## ✨ Features & Capabilities

coZify is built for speed, privacy, and beautiful design. It's a comprehensive platform to track expenses, set goals, and manage your financial life.

### 📊 1. Daily Budget Allowance & Top-Up Engine
- **Circular Budget Burn-Rate Ring:** Visual progress indicator displaying today's spent percentage against your daily spending allowance.
- **Inline Budget Top-Ups:** Instantly increase your daily budget allowance (`+₹50`, `+₹100`, `+₹200`, `+₹500`, `+₹1000`) with custom notes.
- **Target Budget Management:** Customize your default daily spending target allowance at any time.

### 💸 2. Dynamic Transaction & Custom Category System
- **Comprehensive Expense Tracking:** Record transactions with custom titles, amounts, timestamps, and vibrant color accents.
- **Smart Categories:** Built-in categories paired with Lucide icons and deterministic HSL color mappings.
- **Inline Custom Category Creation:** Easily create new custom categories on the fly.
- **Swipe-to-Delete:** Intuitive horizontal swipe gesture with native haptic vibration feedback.

### 👤 3. Multi-Account Management
- **Multiple Saved Accounts:** Store multiple user profiles on a single device and switch seamlessly.
- **User Profile Personalization:** Customize your display name, avatar URL, age, and more.

### 📈 4. Visualizations, Analytics & Timeline Flow
- **Home Dashboard:** Real-time spending breakdown and quick action buttons for Wallet, Cards, Budget, and Goals.
- **Timeline Flow:** A complete chronological transaction stream with date filtering.
- **Deep Analytics:** Switch between 7-day daily spending bars and 12-month annual spending trajectories. Dynamic category spending breakdowns.

### 💳 5. Wallet, Payment Cards & Savings Goals
- **coZify Wallet:** Centralized net worth and liquidity summary.
- **Virtual Payment Cards:** Add custom credit/debit cards with personalized cardholder names and premium gradients.
- **Savings Goals:** Set milestones with visual progress bars and custom glow themes.

### 🎨 6. UI/UX Design System
- **7 Core Theme Paradigms:** Includes Cyberpunk Pink, Neon Emerald, Deep Sapphire, Sunset Gold, Midnight Purple, Slate Minimal, and Arctic Blue.
- **Dark & Light Modes:** Fully responsive color palettes for premium glassmorphism and clean light aesthetics.
- **Hardware-Accelerated Motion:** Smooth spring animations and layout transitions powered by Framer Motion.

### 🔒 7. Local-First Privacy & Cloud Backup
- **100% Local-First Storage:** All financial data is stored locally on the user's device via Zustand.
- **Optional Firebase Cloud Sync:** One-tap Google authentication and Firebase Firestore synchronization.
- **Data Portability:** Export full JSON backups or restore from offline backup files anytime.

## 🛠️ Tech Stack

- **Frontend:** [React](https://react.dev/), [Vite](https://vitejs.dev/), [Tailwind CSS](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Backend/Sync:** [Firebase](https://firebase.google.com/)

## 🏃‍♂️ Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mustaq47/coZify-Website.git
   cd coZify-Website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
